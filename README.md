## Pavee OS

This repository is currently not my main focus however it will form the basis for my
**own** "respin", a very light layer atop `barney` and `bny-base`.

On the one hand it will serve as a test vehicle for `bny-base`, the other is ensuring that
any changes in `barney` and `bny-base` (and other layers) are supportive of ecosystem
expansion rather than locking down to support only a single truth (vendor lock in).

The "binary cache" (public built artefacts) for all layers will always be public and free,
and the source for all components / recipes will always be free. For this particular repository
and "Pavee OS", only the recipes will be publicly available. The actual *builds* will be available
only to supporters via Ko-fi or GitHub sponsors.

**PAYWALL!!** - nah. The vast majority of the build artefacts will be available freely and anyone
will be able to use the tooling to produce Pavee OS from source. The actual aim is to ensure that
there is support and fiscal freedom to **pay** for the hosting and production of those artefacts,
as it will not be remotely cheap for me to do so.

The ambition is to develop a desktop experience in Pavee OS that befits the architecture and tooling,
a reason to keep refining, and to unify to the point of ultimate irony: Pavee OS becomes a trivial
"wallpaper respin" of `barney`, `bny-base` and other layers. First fun item will be embracing recipe
properties to post-add branding changes without butchering/forking layers.

This project will become my own daily driver and in time others, and a way to continue funding the
development of the Barney ecosystem. By building a generic "distro" reference platform and placing
Pavee OS on top of it, it ensures everyones interests are respected, and eliminates committee formation
that attempts oversight of domains without the experience to pull it off. Vested developers and contributors
will focus on the tooling, or the core recipe set (or additional layers) whilst I alone will focus on
"my distro" - Pavee OS.

At all times I retain sole ownership of the entire **mission** of Barney. This is an old school hacker reboot
of distro dev done right.
